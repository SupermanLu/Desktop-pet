# 桌宠 (DeskPet)

一个住在 Windows 桌面的可爱宠物，用 PySide6 编写。它会走路、打哈欠、睡觉、翻口袋、聊天、陪你专注、定时提醒你喝水休息……慢慢养成一个有感情的小家伙。

## ✨ 功能特性

- 🐾 **桌面形象**：支持自定义图片素材（GIF/PNG），内置哆啦A梦程序绘制形象
- 🚶 **自由游走**：在屏幕上缓慢走动、眼睛跟随光标、拖拽移动、拖到屏幕边缘自动挂边待机
- 💬 **AI 聊天**：接入 OpenAI 兼容接口（默认智谱 GLM 免费模型），未配置 Key 时自动回退本地规则聊天
- 📋 **剪贴板助手**：复制链接/代码/命令时弹出气泡，可收藏、保存到沙盒、让 AI 解释
- 🍅 **番茄钟**：专注计时 + 形象轮换，完成得经验、攒彩蛋
- 🏆 **成长系统**：喂食、聊天、专注、猜拳都能攒经验升级，解锁成就称号
- ⏰ **关怀提醒**：饭点、喝水、久坐、深夜、整点鼓励、专注鼓励
- 🎮 **猜拳小游戏**：和宠物玩石头剪刀布，赢蛋攒惊喜
- 🔇 **防打扰模式**：一键鼠标穿透，看视频/打游戏不挡操作
- 🔊 **音效**：程序合成音效（交互/聊天/提醒/彩蛋），可调音量
- 🌍 **全屏检测**：前台窗口全屏时自动挂边/隐藏，不打扰观影

## 🚀 运行

```bash
pip install -r requirements.txt
python main.py
```

## 🖼 素材说明

- 所有形象/动作图片放在 `assets/桌宠/` 目录
- 表情、动作、道具、节日图、番茄钟、猜拳等场景图片按配置映射
- 首次运行会自动在 `assets/sfx/` 生成程序合成音效

## ⚙️ 配置

配置文件 `config.json` 在首次运行时自动生成（含你的 API Key，已加入 `.gitignore` 不会上传）。

主要配置项：
- `pet_gif`：基础形象图片路径
- `action_img_dir` / `idle_dir`：动作与待机素材目录
- `ai_enabled` / `ai_api_key` / `ai_model`：AI 对话配置
- `wander`：是否游走
- `autostart`：开机自启（通过注册表 Run 键）
- `sfx_enabled` / `sfx_volume`：音效开关与音量
